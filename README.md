# لعبة الأرشيف

لعبة فرز وترتيب أرشيفي بمناسبة **اليوم الوطني السعودي ٩٦**.
محتوى الأرشيف: بصمة **الأمير مساعد بن عبدالرحمن آل سعود**، رحمه الله،
في بناء مؤسسات الدولة — من كتابه عام 1360هـ إلى إطلاق اسمه على الجامعة
السعودية الإلكترونية عام 1448هـ.
إنتاج: **كلية الحوسبة والمعلوماتية**.

## البنية

```
index.html        الهيكل (نسخة التطوير: تشير إلى الملفات المنفصلة)
src/data.js       الوثائق والمصادر  ← عدّل هنا لتغيير المحتوى
src/game.js       منطق اللعبة
src/styles.css    التنسيقات
assets/           الشعار (أيقونة · اسم · كامل)
build.py          يدمج كل شيء في dist/index.html
dist/index.html   ملف التسليم الواحد المكتفي ذاتيًا
```

## التطوير

افتح `index.html` مباشرة في المتصفح. لا حاجة لخادم أو تثبيت أي شيء.

## البناء قبل التسليم

```bash
python3 build.py
```

يُنتج `dist/index.html`: ملف واحد يحوي التنسيقات والكود والشعار مضمّنًا،
بلا أي طلب شبكة خارجي.

## تعديل المحتوى

كل شيء في `src/data.js`:

- ترتيب عناصر `FILES` هو **الترتيب الزمني الصحيح** في مرحلة الترتيب.
- لكل ملف: `name` و`date` و`event` و`source` و`url` ومصفوفة `scraps`.
- كل قصاصة: `kind` (نوع الورقة) و`text` (نصها) و`key` (التلميح عند الخطأ).
- لحذف ملف: احذف كائنه كاملًا — اللعبة لا تفترض عددًا معينًا للملفات
  ولا للقصاصات داخل كل ملف.
- `source` و`url` لكل ملف يظهران في نافذة «المصادر» داخل اللعبة.

`FORM_URL` في `src/data.js` هو رابط نموذج إتمام المشاركة (يرفع فيه اللاعب
بطاقة الإنجاز ويلصق رمز الإتمام).

## رمز الإتمام

`ARK-MMSS-TT-X` — المدة (دقائق وثوانٍ)، ثم المحاولات الخاطئة، ثم حرف تحقق.
للتحقق: اجمع الأرقام الستة، اضرب في ٧، أضف ٣، وخذ الباقي على ٢٣ ليعطيك
موضع الحرف في `ABCDEFGHJKLMNPQRSTUVWXY`.

## ملاحظات النشر

- الملف المسلَّم ثابت بالكامل: لا خادم، ولا قاعدة بيانات، ولا جمع بيانات.
- لا يتصل بأي نطاق خارجي. `localStorage` يُستخدم لحفظ التقدم داخل `try/catch`.
- محتوى الوثائق مقتصر على وقائع تتفق عليها مصادر متعددة، وروابطها في
  نافذة «المصادر» داخل اللعبة.
